# 创造性机制参考 | Creative Playbook

这里是“探索时的视角工具箱”，不是要求模型照顺序套用的作文模板。真正的创意应来自具体任务的限制、参与者、因果关系与可能价值。

## 1. 七种跳跃操作

| 机制 | 可问的问题 | 产出的变化 |
|---|---|---|
| 前提反转 | 什么步骤只是旧条件下的习惯？ | 移除旧前提后出现新路径 |
| 目标迁移 | 用户追求的载体是否只是某个中间物？ | 从产物导向变为结果/体验导向 |
| 结构类比 | 完全不同的行业，是否具有相似的角色、约束和反馈环？ | 移植深层机制，不照抄界面 |
| 关系重构 | 谁是生产者、消费者、编辑者、决策者？换位会发生什么？ | 出现新角色和协作方式 |
| 时序重排 | 这件事为什么必须在此时发生？ | 事前/事中/事后重新分工 |
| 条件消失 | 如果必须存在的限制暂时不成立，创造什么新体验？ | 发现旧边界掩盖的可能性 |
| 副产品转正 | 正在被扔掉的过程、记录和反馈能否产生独立价值？ | 新型资产或新产品 |

### 使用深层类比的三步

1. 明确原任务的**关系结构**，例如“学习者遇到障碍 → 寻找教程 → 回到工作”。
2. 在其他领域寻找相似结构，例如游戏的即时任务指引，**不要假定它们天然可迁移**。
3. 说明映射条件与失效条件，例如高风险专业操作不能照搬游戏里的试错逻辑。

## 2. 三层意外

- **方法意外**：目标不变，解决办法变。例如静态教程变成工作现场的即时引导。
- **目标意外**：重新发现更有价值的目标。例如从“提升内容阅读率”转为“让读者完成一次真正有意义的行动”。
- **可能性意外**：从当前任务外延发现新方向。例如做一份工具教程时发现“把重复教程变成别人可安装的微型操作助手”这个新产品类别。

不要一味偏爱第三层。弱关联的大跨度不一定优于准确的小跳跃。

## 3. 创意生成四原则

1. **真实摩擦**：发现用户为何以现有方式处理任务。是什么限制、机会成本或默认习惯？
2. **有效违反常识**：改变一个前提，而不是一次推翻全部事实。
3. **新行为**：说清人或系统将出现什么之前做不到/没想到的行动，而不是停留在概念词。
4. **最小反证**：提供最便宜的方式发现它也许根本不可行。

## 4. 候选发散与筛选示例

问题：“能不能让产品介绍更吸引客户？”

普通发散：改配色、增加短视频、上 3D 展示、做互动网页。缺点：全是形式叠加。

可能性候选：
- 客户从头看完介绍才知道是否适用 → 让其从一个自我诊断问题进入产品体验。
- 作者讲产品功能 → 让使用者以自己的目标组织接收顺序；作者保留关键信息校验。
- 介绍一次就结束 → 形成一个可带走的可复用决策清单，成为沟通后续的共同语言。

其中哪一个值得提交，取决于用户是否真的存在那个瓶颈。不可暗称验证通过。

## 5. 非商业创意同样有效

- 写作：让作品中的边缘物件成为叙述者，改变情绪而非简单换文风。
- 旅行：不是多景点清单，而是以一段故事或兴趣主题重新理解地点。
- 学习：不是多练习题，而是把错误当作反向构建概念的入口。
- 个人计划：不是更细的日程，而是改变做决定的频率或规则。
- 艺术：不是多加装饰，而是改变观众与作品的关系。

重要提醒：用户如果只想要一个最终作品，就别把它强行变成“用户体验系统”。
